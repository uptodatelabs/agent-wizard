# AgentWizard

AI coding assistant configuration wizard. Set up your AI tools in minutes, not hours.

## Features

- **Multi-tool support**: Claude Code, Cursor, Copilot, Aider, and more
- **Smart detection**: Automatically detect your project type and tech stack
- **Quality scoring**: Curated agents and skills with quality ratings
- **One command setup**: Get started with a single CLI command

## Installation

```bash
npm install -g agent-wizard
```

## Quick Start

```bash
# Initialize your project
agent-wizard init

# Detect your project
agent-wizard detect

# Configure interactively
agent-wizard configure
```
