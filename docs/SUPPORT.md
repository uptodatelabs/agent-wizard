# Supporting AgentWizard

AgentWizard is **free, open-source software** (MIT License). It is built by one
person, in public, the same way [CodeNexus](https://github.com/uptodatelabs/CodeNexus)
is. There is no paywall, no subscription, and no "Pro" tier — the CLI you get
is the CLI we use.

If AgentWizard saves you time, the best ways to give back are:

## 1. Donate

Your support directly funds maintenance, bug fixes, and new tool adapters.

[![Ko-fi](https://img.shields.io/badge/Ko--fi-FF5E5B?style=for-the-badge&logo=ko-fi&logoColor=white)](https://ko-fi.com/uptodatelabs)
[![GitHub Sponsors](https://img.shields.io/badge/Sponsor-AgentWizard-ea4aaa?style=for-the-badge&logo=githubsponsors&logoColor=white)](https://github.com/sponsors/uptodatelabs)

## 2. Contribute

- **Report bugs** — open a [GitHub issue](https://github.com/uptodatelabs/agent-wizard/issues)
- **Propose features** — start a [discussion](https://github.com/uptodatelabs/agent-wizard/discussions)
- **Send a PR** — keep `npm run verify` (lint + typecheck + test + build) green
- **Star the repo** — it genuinely helps other developers find the project

## 3. Spread the word

Mention AgentWizard where people struggle with AI coding assistant setup —
forums, meetups, blog posts. Word of mouth is the most valuable contribution
there is.
