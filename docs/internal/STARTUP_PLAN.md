## 1단계: 가입 및 설정 (Week 1)

### 1.1 LemonSqueezy 계정 생성

```
[ 필요 서류 ]
├── 이메일 주소
├── 정부 발급 신분증 (여권, 주민등록증, 면허증)
└── 은행 계좌 (USD 입금 가능)

[ 가입 절차 ]
1. lemonsqueezy.com 접속
2. 이메일/비밀번호 또는 Google/Twitter 가입
3. 이메일 인증
4. 스토어 활성화 설문조사
5. 본인인증 (신분증 업로드)
```

**출처:** docs.lemonsqueezy.com/guides/getting-started

### 1.2 W-8BEN 세금 양식 작성

| 항목 | 기재 내용 | 비고 |
|---|---|---|
| **Line 1 (이름)** | 영문 이름 | 여권 기준 |
| **Line 2 (국적)** | KOREA, REPUBLIC OF | |
| **Line 3 (주소)** | 한국 주소 | 영문 기재 |
| **Line 5 (TIN)** | 주민등록번호 또는 외국인등록번호 | |
| **Part II (조세조약)** | 한미 조세조약 제7조 적용 | 미국 세금 0% |

**출처:** IRS (irs.gov/forms-pubs/about-form-w8-ben)

### 1.3 출금 설정

```
[ 출금 방법 ]
├── 한국 은행 계좌 (USD 입금 가능)
│   ├── 지원 은행: 우리, 신한, 하나, 국민 등
│   ├── 송금 수수료: 약 $10-20
│   └── 환전 수수료: 은행별 상이
│
└── PayPal (USD 수령)
    ├── 수수료: 3% (최대 $30)
    └── 환전 후 한국 계좌로 출금
```

**출처:** docs.lemonsqueezy.com/help/getting-started/getting-paid

## 4단계: 세금 관리 (매출 발생 시)

### 4.1 세금 신고 타임라인

| 시점 | 신고 내용 | 출처 |
|---|---|---|
| **연간** | 종합소득세 신고 (5월) | 소득세법 |
| **매출 300만원 이상** | 사업자등록 검토 | 부가가치세법 |
| **매출 800만원 이상** | 사업자등록 필수 | 부가가치세법 시행령 |

### 4.2 세금 계산 예시

**연 매출 $5,000 (약 650만원) 기준:**

```
[ LemonSqueezy 수수료 ]
├── 플랫폼 수수료: 5% + $0.50 = $300
├── 해외 카드 수수료: 1.5% = $75
├── 출금 수수료: 1% = $50
└── 총 수수료: $425 (8.5%)

[ 실수령 ]
├── 총 매출: $5,000
├── 수수료: $425
├── 실수령: $4,575 (약 595만원)

[ 국내 세금 (종합소득세) ]
├── 과세표준: 595만원
├── 세율: 6% (1,400만원 이하)
├── 소득세: 약 35.7만원
├── 지방소득세: 약 3.57만원
└── 총 세금: 약 39.27만원

[ 최종 실수령 ]
└── 약 555만원 (약 $4,270)
```

## 5단계: 사업자등록 전환 시점 (매출 300만원~800만원)

### 5.1 사업자등록 필요성 판단

| 기준 | 불필요 | 필요 |
|---|---|---|
| **매출** | 300만원 이하 | 800만원 이상 |
| **활동** | 일회성/취미 | 정기적/반복적 |
| **의도** | 부수입 | 주수입 |

**출처:** 국세청 사업자등록 안내

### 5.2 사업자등록 시 절세 효과

| 항목 | 개인 (미등록) | 사업자등록 후 |
|---|---|---|
| **VAT** | 10% (일반) | 1% (간이) 또는 0% (영세율) |
| **세금 공제** | 불가 | 사업비 공제 가능 |
| **장부** | 간이장부 | 별도장부 |

### 5.3 사업자등록 절차

```
[ 준비 서류 ]
├── 신분증
├── 사업장 임대차계약서 또는 무점포 확인서
├── 통장 사본
└── 업종: 소프트웨어 개발 및 공급업 (58200)

[ 신청 방법 ]
├── 홈택스 (hometax.go.kr) - 온라인
└── 관할세무서 - 방문

[ 처리 기간 ]
└── 즉시~3일
```
